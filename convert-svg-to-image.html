🖼️ Конвертер Open Graph изображения

📋 Инструкция:

  1. Нажмите "Загрузить SVG" чтобы отобразить изображение
  2. Нажмите "Скачать как JPG" для получения финального файла
  3. Сохраните файл как og-image.jpg в корень проекта
  4. Размер изображения: 1200×630 пикселей (идеально для Open Graph)

SVG изображение появится здесь

🔧 Альтернативные способы:

  • Онлайн конвертеры: Convertio, CloudConvert
  • Установить ImageMagick: brew install imagemagick → convert og-image.svg og-image.jpg
  • Photoshop/GIMP: Открыть SVG → Экспорт → JPG (1200×630px)
